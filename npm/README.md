# lookfirst (pointer)

**lookfirst is a Python command-line tool, not an npm package.** This package exists only so that nobody else can publish something under the name `lookfirst` on npm. It has no install scripts and no dependencies, and its one command only prints how to install the real tool.

Install lookfirst with [uv](https://docs.astral.sh/uv/):

```bash
uv tool install lookfirst
```

lookfirst checks a GitHub repo, a `curl | bash` line or a package before you or your AI agent runs it. Read more at **[github.com/lookfirst-dev/lookfirst](https://github.com/lookfirst-dev/lookfirst)**.

**Official sources:** the GitHub repository above, the `lookfirst` package on PyPI, and this pointer on npm. Anything else using the name isn't ours.
